# 나의 시험 준비 · 변형 문제 연습

작성: 2026-11-27. 메인 화면의 "기말고사 집중 복습" 메뉴(#review) 맨 위에 학생마다 다른 "나의 시험 준비" 패널을 두었다. 기존 집중 복습 20문항은 그 아래(#review-path)에 그대로 있다.

## 준비도와 예상 점수 (public/readiness.js)

- 대상: 기말 범위인 공간도형·공간좌표, 벡터의 문제은행 40문항과 실험 확인 문제 8개. 이 브라우저의 채점 기록과 오답노트만 쓴다.
- 문항 가중치: 기본 1, 적용 2, 도전 3, 실험 2.
- 문항 성취: 한 번에 맞힘 1, 여러 번 만에 맞힘 0.8, 오답노트 졸업 1, 남은 오답은 맞혔어도 0.5, 틀림 0. 안 푼 문항은 계산에서 뺀다.
- 숙련도 게이지: 단원 전체 가중치에 대한 비율이다. 문제를 풀수록 차오른다.
- 예상 점수: 단원별로 푼 문항의 성취를 쓰되, 푼 문항이 적을 때 치우치지 않도록 60%를 가중치 4만큼 섞어 추정한다. 두 단원을 50 : 50으로 합친다.
- 표시 방식: 범위로 보여 준다. 범위의 절반 너비는 4~15점이고, 푼 문항이 많을수록, 범위를 많이 풀수록 좁아진다.
- 공개 조건: 기말 범위 15문항 이상, 단원마다 4문항 이상. 그 전에는 "n문항 더 풀면 공개돼요"를 보여 준다.
- 실제 시험 결과로 맞춰 본 공식이 아니므로 화면에 "참고용 예측"이라고 밝힌다.

## 오답 유형 맞춤 복습

- 오답노트에 남은 기말 범위 문제(문제은행, 실험, 복습 20문항)를 변형 문제 유형으로 묶는다.
- 묶음마다 "변형 문제로 연습(연속 n/3)" 링크와 같은 유형의 안 푼 문제은행 문항을 보여 준다.
- 남은 오답이 없으면 숙련도가 낮은 단원부터 기본 → 적용 → 실험 → 도전 순으로 안 푼 문제를 추천한다.

## 변형 문제 (public/drill/generators.js, drill.html)

- 공간 10유형: 두 점 사이의 거리, 대칭점, 내분점, 무게중심, 구의 방정식(완전제곱), 구와 좌표평면의 단면, 구에 접하는 평면, 정사영, 삼수선, 두 직선의 위치 관계.
- 벡터 11유형: 덧셈과 실수배, 평행, 수직 조건, 크기와 각으로 구하는 내적, 크기와 단위벡터, 두 벡터가 이루는 각, 수선의 발, 평면의 방정식, 점과 평면 사이의 거리, 직선과 평면의 교점, |a − tb|의 최솟값.
- 정답이 깔끔하게 나오도록 숫자를 만든다. 피타고라스 수, 나누어떨어지는 내분, 크기 3인 법선벡터 등을 쓴다. 문제마다 정답, 힌트 2단계, 풀이가 함께 만들어진다.
- 같은 번호(seed)는 항상 같은 문제다. 주소에 type과 seed가 남는다.
- 한 유형에서 3문제를 연속으로 맞히면 "연습 완료"다. 기록은 localStorage `geometry-drill-v1`에 남고, 예상 점수와 오답노트에는 반영하지 않는다.

## 검증 (scripts/verify-exam.mjs)

- 21유형마다 seed 1~400을 생성해 8,400문항을 확인한다. 정답은 생성기와 별도로 다시 계산한다. 구의 방정식은 문제 문장의 계수를 읽어 거꾸로 계산하고, 두 직선의 위치 관계는 삼중곱으로 판정한다.
- 수식은 KaTeX로 렌더링해 확인한다. 유형마다 서로 다른 문제가 30개 이상인지, 같은 seed가 같은 결과를 내는지도 확인한다.
- 모든 기말 범위 문제은행 유형, 복습 20문항, 실험이 변형 유형에 연결되어 있는지 확인한다.
- 준비도 규칙: 빈 기록, 전부 정답, 전부 오답, 단원별 최소 문항, 오답·졸업·재시도 반영, 범위가 좁아지는지, 항상 0~100 안인지 확인한다.
- 화면: 잠금 상태와 점수 범위 표시, 맞춤 복습 링크, 변형 문제 채점·연속 정답·완료, 좁은 화면을 확인한다.
