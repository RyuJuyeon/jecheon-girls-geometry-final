## 학습 기록 내보내기 · 불러오기

- 내보내기: 집중 복습 자기 점검, 문제은행 자기 점검, 채점 기록, 오답노트, 변형 문제 연습, 정육면체 단면 찾기 기록을 `geometry-record-YYYYMMDD.json` 파일로 저장한다. 손풀이 필기는 포함하지 않는다.
- 불러오기: 파일 내용을 먼저 보여 주고 "지금 기록과 합치기"를 눌러야 반영한다. 합칠 때는 더 많이 진행한 쪽을 남긴다. 맞힌 기록, 많은 시도 횟수, 최근 오답노트 상태, 완료한 연습이 남는다. 같은 파일을 다시 합쳐도 바뀌지 않는다.
- 이 사이트가 만든 파일만 받는다. 모르는 항목, 잘못된 값, 형식이 다른 ID는 버리고, 2MB가 넘는 파일은 거부한다.

## 결과 요약 코드

- 형식은 `GEO1-<내용>-<검사 4자리>`다. 내용에는 작성 주차, 단원별 채점 수·전체 수·준비도, 준비 단계, 변형 유형별 남은 오답 수, 틀린 이유 4가지 개수, 졸업 수, 변형 연습 완료 유형만 담는다.
- 이름, 학번, 입력한 답, 문제별 기록, 정확한 날짜는 담지 않는다. 학생 화면의 "이 코드에 담긴 내용 보기"에서 확인할 수 있다.
- 교사 페이지는 붙여넣은 글에서 코드만 골라낸다. 똑같은 코드는 한 번만 세고, 검사 자리가 맞지 않는 코드는 뺀다. 모든 계산은 브라우저 안에서 한다.
- 구글 폼 주소를 `content/platform.mjs`의 `summaryFormUrl`에 넣으면 학생 화면에 "제출하러 가기" 버튼이 생긴다. docs.google.com/forms 또는 forms.gle 주소만 받는다. 비워 두면 "선생님이 안내한 곳에 붙여넣기"로 안내한다.

## 검증 (scripts/verify-feedback.mjs)

- 개수가 데이터와 같은지, 모든 페이지에 "단원별 개념 학습 준비 중", "창작 20문항", "예상 점수"가 남아 있지 않은지 확인한다.
- 백업: 정리, 합치기 규칙, 같은 파일을 다시 합쳐도 그대로인지, 잘못된 파일 거부를 확인한다. 화면에서 내보낸 파일을 다른 브라우저(390px)에서 불러와 오답노트와 준비도가 이어지는지 확인한다.
- 요약 코드: 왕복 변환, 변조 감지, 개인정보가 없는지, 교사 페이지의 중복·오류 처리와 CSV 저장을 확인한다.
