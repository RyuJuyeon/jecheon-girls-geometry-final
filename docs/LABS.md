# 기하 실험실 1차 (공간도형·공간좌표, 벡터)

작성: 2026-11-27. 기말고사 범위를 먼저 반영해 공간·벡터 실험 8개를 추가했다. 이차곡선 실험은 다음 단계에서 만든다.

## 출처와 저작권

교과서(2022 개정 기하)의 탐구 활동 유형을 참고했다. 참고한 활동은 디지털 공학 탐구, 개념 탐구, 실생활 탐구, 창의·코딩 프로젝트다. 실험의 상황, 수치, 문장, 그림은 모두 새로 만들었다. 교과서 PDF, 본문, 그림, 수치는 저장소와 사이트에 넣지 않았다.

| 실험 | 파일 | 참고한 활동 유형 |
|---|---|---|
| 정육면체 자르기 (3D) | lab-cube-section | 공학 도구로 정육면체의 단면 찾기 |
| 그림자와 정사영 (3D) | lab-shadow | 그림자 모양 추측, 그림자의 넓이 탐구 |
| AP + PB의 최솟값 (3D) | lab-shortest-path | 평면 위 점까지 거리의 합의 최솟값 탐구 |
| 좌표축과 좌표평면에 접하는 구 (3D) | lab-tangent-sphere | 공학 도구로 축에 접하는 구 탐구 |
| 공간벡터의 덧셈과 실수배 (3D) | lab-vector-ops | 공학 도구로 공간벡터의 연산 관찰 |
| 강을 건너는 배 (2D) | lab-boat | 실생활 속 속도와 벡터의 합 |
| 직선과 평면의 위치 관계 (3D) | lab-line-plane | 공학 도구로 직선과 평면 나타내기 |
| 벡터로 취향 비교하기 (3D) | lab-similarity | 벡터를 이용한 유사도 프로젝트 |

## 구성

- 실험마다 도입 질문 → 조작 화면과 패널 → 관찰하기(단계) → 확인하기(자동 채점) → 알게 된 사실 정리 → 이어서 풀 문제은행 문항으로 구성한다.
- 시작 화면에서 확인 문제의 답이 바로 보이지 않도록 초기값과 프리셋을 정했다. 예를 들어 오각형·육각형 단면은 프리셋 없이 학생이 직접 찾는다.
- 3D는 Three.js 0.187.0(MIT)을 로컬 자원으로 배포한다(dist/assets/three). 끌어서 회전하고, 휠이나 두 손가락으로 확대한다. WebGL을 쓸 수 없으면 안내문을 보이고, 수치와 확인 문제는 그대로 이용할 수 있다.
- 계산 함수는 public/labs/geometry.js에 두고, 브라우저와 검증 스크립트가 같이 쓴다.
- 확인 문제 채점은 문제은행과 같은 채점 엔진(answer.js)을 쓰고, 기록은 브라우저에만 저장한다.

## 검증 (scripts/verify-labs.mjs)

- 확인 문제의 정답을 문항 데이터와 별도로 다시 계산한다. 대상은 단면, 정사영, 대칭점·최단거리(격자 탐색으로도 확인), 축까지의 거리, 벡터 합, 속도 합성, 직선과 평면의 교점, 코사인 유사도다.
- 정육면체 단면은 프리셋 6종의 모양을 분류하고, 여러 평면에서 단면이 많아야 육각형인지 확인한다.
- 브라우저에서는 8개 페이지의 로딩, 수식, 링크, 390/320px 화면을 확인하고, 실험마다 값을 조작해 계산 결과를 대조한다. 실험의 확인 문제 채점도 검사한다.
- 로컬 Linux 테스트에서는 CHROME_PATH로 시스템 Chrome을 지정할 수 있다.
