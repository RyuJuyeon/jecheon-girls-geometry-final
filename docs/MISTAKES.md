# 오답노트

작성: 2026-11-27.

## 흐름

1. **자동 수집**: 문제은행 60문항이나 실험 확인 문제를 채점해서 하나라도 틀리면 오답노트에 자동으로 담긴다. 자동 채점이 없는 기말고사 집중 복습 20문항은 문제 아래 "틀렸다면 오답노트에 추가" 버튼으로 직접 담는다.
2. **틀린 이유 (필수)**: 개념을 잘못 알았다 / 조건을 잘못 읽었다 / 계산 실수 / 풀이 방법을 떠올리지 못했다 중에서 고르고, "다음에는 이렇게 하겠다"를 한 줄 쓴다. 이유를 고르지 않으면 졸업하지 않는다.
3. **졸업**: 마지막으로 틀린 날과 **다른 날** 다시 맞히면 졸업한다. 같은 날 바로 맞힌 것은 답을 기억해서일 수 있기 때문이다. 졸업한 문제를 다시 틀리면 오답노트로 돌아온다. 복습 20문항은 다른 날 스스로 다시 풀고 "다시 풀어 맞혔어요"를 눌러 졸업한다.

## 오답노트 페이지 (mistakes.html)

- 남은 오답 수, 졸업 수, 이유를 고르지 않은 수, 단원별로 남은 개수를 보여 준다.
- "나는 주로 왜 틀릴까?" 이유별 막대그래프와 가장 많은 이유를 보여 준다.
- 보기(남은 오답 / 졸업 / 전체)와 단원으로 거를 수 있고, 거른 조건은 URL에 남는다.
- 카드에는 문제, 내가 쓴 답, 날짜와 틀린 횟수, 이유, 다짐, 다시 풀기 링크, 정답·해설·오개념이 들어간다.
- "오답노트에서 빼기"는 실수로 지우지 않도록 두 번 눌러야 한다.

## 제출용 인쇄

- 학년·반·번호·이름을 입력하고 "인쇄 · PDF 저장"을 누르면 A4 양식으로 인쇄된다. 인쇄 창에서 PDF로 저장할 수도 있다.
- 인쇄물에는 이름 머리글, 인쇄한 날, 문항 수, 문제, 내가 쓴 답, 틀린 이유, 다짐이 들어간다. 정답·해설은 선택해서 넣는다.
- 이름 칸은 저장하지 않는다. 인쇄할 때만 쓰인다.

## 저장과 개인정보

- localStorage `geometry-mistakes-v1`에만 저장하고 서버로 보내지 않는다. 기기나 브라우저를 바꾸면 기록이 이어지지 않는다.
- 손풀이 필기는 아직 오답노트 인쇄에 포함하지 않는다.

## 함께 고친 점

- 메인 화면의 기말고사 집중 복습 20문항에서 텍스트 풀이 칸 아래에 숫자(0, 1, 2…)가 보이던 문제를 고쳤다. 지난 업데이트에서 생긴 문제였다.

## 검증 (scripts/verify-mistakes.mjs)

- 규칙 테스트는 Node에서 날짜를 바꿔 가며 한다. 처음부터 맞힌 문제는 담지 않음, 이유 필수, 같은 날 졸업 불가, 다음 날 졸업, 자정 경계, 재오답 시 다시 열림, 잘못된 이유 값 거부, 수동 추가와 스스로 확인, 빼기, 입력 길이 제한, 손상된 저장값을 확인한다.
- 화면 테스트는 채점 후 자동 수집, 이유 저장, 다른 날 졸업, 이유 없이 맞힌 실험 문항, 복습 문항 수동 추가, 필터와 URL, 두 번 눌러 빼기, 인쇄 머리글, 이름 미저장, A4 PDF 출력, 390/320px 화면을 확인한다.
