# 단원별 창작 문제은행 1차 반영

작성: 2026-11-22 / 최종 검토: 2026-11-27. 기존 20문항과 손풀이 기능을 유지하면서 창작 24문항을 추가했다.

## 학습 기능

- bank.html: 단원·난이도·유형/제목 검색, 검색 결과 수, 빈 결과 안내, URL로 필터 유지.
- practice-b-*.html: 문제별 독립 정적 페이지. 손풀이, 텍스트 풀이, 단계별 힌트, 정답, 해설, 오개념, 자기 점검을 제공한다.
- 새 문제는 이차곡선 8개, 공간도형과 공간좌표 8개, 벡터 8개다. 각 단원은 기본 3개·적용 3개·도전 2개다.
- 모든 주소와 자원은 상대 경로다. GitHub Pages 저장소 하위 경로에서 동작하며 라우터나 서버 재작성 규칙이 필요 없다.
- 문제를 한 페이지씩 열어 24개의 필기 캔버스를 동시에 생성하지 않는다. 기존 필기 저장소를 재사용하되 새 ID(b-c01 등)로 기록을 분리한다.
- 문제은행 완료 체크는 별도 localStorage geometry-bank-progress-v1에 저장한다. 정답 판정·정답률이 아니라 사용자의 자기 점검이다. 학습 기록은 서버에 전송하지 않는다.
- 자동 채점, 교과서 원문 검색·열람, 새로운 PDF 문제집 생성 기능은 이번에 추가하지 않았다.

## 자료 분석과 반영 범위

사용자가 제공한 PDF 9개와 HWP 26개를 공개 저장소 바깥에서 처리했다. PDF 본문의 텍스트와 HWP 문단 텍스트를 추출했으며 문항정보표의 평가 내용·난이도 분류를 확인했다. 이차곡선 접선 설명과 교과서 차례는 렌더링 이미지로 대조했다. 특수 수식 글꼴과 HWP 수식 개체·도형은 전체 문항 수준으로 완전히 복원하지 않았으므로 원본 문제 전체를 검토·전사·검산했다고 주장하지 않는다.

확인한 범위:
- 이차곡선: 포물선·타원·쌍곡선의 정의와 방정식, 초점·축·점근선, 접선과 판별식.
- 공간도형/좌표: 직선·평면 위치 관계, 삼수선, 정사영, 거리, 내분점, 구.
- 벡터: 성분 연산, 평행, 내적, 각, 직선·평면·구의 표현.

이번 24문항은 이 학습 범위와 평가 유형을 참고하여 조건·수치·문장·힌트·해설을 새로 작성한 자체 제작 문제다. 원문·도표·교과서 페이지·추출 텍스트·기존 학교 시험 자료는 저장소나 사이트에 포함하지 않았다. 출판사 인증/제공 문제로 표시하지 않는다. 문항별 표시 항목은 주제이며, 신규 문항의 공식 성취기준 코드 대조를 완료한 것으로 표시하지 않는다. 전체 교육과정 또는 모든 출판사의 문항을 빠짐없이 다루는 문제은행은 아니다.

## 유지한 기능과 검증

기존 content/course.mjs의 20문항, 2차시, 성취기준 스냅샷, PDF 생성기, 기존 7종 PDF 구성을 유지했다. 새 24문항은 웹 학습 전용이며 기존 PDF에는 추가하지 않았다. 기존 PDF 링크와 기능은 문제은행에서도 연결한다.

실행: npm run build, npm run pdf, npm test.
- 기존 20문항 독립 검산·7개 성취기준·차시별 필수 8+도전 2·50분 유지.
- 신규 24문항 답의 독립 수치 검산 및 접선/곡선 대입, 거리 조건, 벡터 관계, 완전제곱 항등식 검증.
- 단원별 8개, 난이도 3/3/2, ID 유일성, 힌트 2단계, 해설·오개념 존재 검증.
- 기존 사이트·노트·PDF 전체 40쪽 회귀 검사 유지.
- 문제은행 1440/768/390/320px, 복합 필터, 빈 결과, 초기화, URL 복원, 24개 문제 페이지의 탭·수식·내부 링크·좁은 화면 검사.
- 새 문제의 텍스트 풀이와 완료 체크 재접속 복원, 문제은행 완료 수, JavaScript 없는 해설 열람 검사.

자동 검사는 교육적 완성도에 대한 교사 검토나 실제 태블릿의 펜/손바닥 입력 검증을 대체하지 않는다.
