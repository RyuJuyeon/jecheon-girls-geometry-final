# 태블릿 손풀이 노트 — 구현 및 검증

2026-11-22. 기준: 공개 main의 병합 커밋 13953d2. 작업: develop-v2. 공개 사이트에 자동 병합·배포하지 않음.

## 제공 기능

기존 필수 16문항·선택 도전 4문항 모두에 손풀이/힌트/정답/해설 탭을 추가했다. 기존 2단계 힌트, 정답 열기, 풀이, 오개념, 자기 점검은 보존한다. JavaScript가 없으면 힌트·정답·해설을 순서대로 읽을 수 있다.

- Pointer Events 기반 펜·마우스 필기. 손가락 필기는 선택 입력이며 기본 비활성이다. 화면 스크롤은 캔버스 밖에서 한다.
- 펜 굵기 3종, 지우개, 실행 취소·다시 실행. 지우개 동작도 취소할 수 있다.
- 필기 전체 삭제는 확인 후 실행하며 복구하지 않는다. 텍스트 풀이는 유지한다.
- PC의 2열 문제 목록에서는 크게 쓰기로 한 줄 전체를 사용한다. 한 열인 모바일·태블릿 세로 화면에서는 해당 버튼을 숨긴다.
- 문제 번호가 포함된 PNG 다운로드. PNG는 손필기만 포함하며 텍스트 풀이는 별도 보관해야 한다.
- 키보드로 입력하는 텍스트 풀이 대안. 탭은 좌우 방향키·Home·End로 이동한다.
- IndexedDB geometry-notebooks-v1/notes에 문제 ID별 획과 텍스트를 저장한다. 추가 서버/API/로그인/개인 식별 정보 수집 없음.
- 불러오기·저장 실패 시 경고하고 현재 화면에서 작성할 수 있게 한다. 기존 완료 체크 초기화는 필기를 삭제하지 않으며 확인 창에 이를 명시한다.
- 문항당 최대 300획·30,000점, 한 획 최대 3,000점, 텍스트 12,000자. 많은 필기는 PNG로 보관 후 지워서 이어 쓴다. 지우개도 하나의 획이다.

손글씨 인식, 정답 자동 채점, 부분점수, 정답률, 오답 자동 분류는 이번에 구현하지 않았다. 서술·근거·방정식의 동치 판정을 정확하게 다루기 위해 사용자가 허용한 손풀이+해설 확인 방식으로 먼저 구현했다. 화면에도 자동 채점이 아니라고 표시한다.

## 변경 파일

- scripts/question.mjs: 기존 문제 카드 렌더링 분리, 노트·탭 및 기존 설명 연결.
- public/notebook.js: 탭 접근성, 펜/터치 라우팅, 캔버스·획 이력, IndexedDB 저장, PNG 출력.
- public/notebook.css: 필기 도구와 노트·탭·반응형 스타일.
- scripts/build.mjs: 문제 렌더러 및 로컬 CSS/JS 연결. 상대 경로 유지.
- public/app.js: 기존 완료 체크 초기화 범위 안내.
- scripts/verify-notebooks.mjs, scripts/verify.mjs: 기능·회귀 테스트.
- README.md, 본 문서: 사용법·한계·다음 단계.
- output/pdf/*.pdf: 기존 생성 명령으로 7개 재생성. 원본 course.mjs, 성취기준, PDF 생성기는 수정하지 않았다.

## 검증

npm run build, npm run pdf, npm test 모두 실행하여 통과했다.
기존 20문항 독립 검산, 7개 성취기준, 차시별 50분, 기존 SVG 시각화, 완료 체크 저장/초기화, 내부 링크, PDF 7종·40쪽 A4·한글·문항 번호·전체 렌더링 검사를 유지했다.

추가 자동 검사: 노트 20개·탭 80개, 마우스 필기, 지우개, 실행 취소/다시 실행, 새로고침 후 필기와 텍스트 복원, 다른 문제와 저장 분리, PNG 다운로드, 1440/768/390/320px 확장 화면, 탭 키보드 이동, 합성 펜/터치 이벤트, 취소된 포인터 처리, 삭제 취소/확인/재접속, IndexedDB 차단 시 경고.

노트 화면은 PC·390px 이미지로 확인했다. 실제 iPad/Apple Pencil 및 Galaxy Tab/S Pen의 펜압·손바닥 접촉·운영체제 제스처는 실기기 검증을 하지 않았다. 합성 포인터 테스트가 실제 기기의 팜 리젝션을 보장하지 않는다. 학생 배포 전 두 기기에서 필기, 회전, 브라우저 종료/재접속, PNG 저장을 확인한다. 현재 필기는 동일 브라우저·동일 사이트 주소에서만 복원되며 다른 기기와 동기화하지 않는다.

## 교과서 기반 후속 작업

교과서 파일은 아직 제공되지 않았으며 이번 코드/공개 저장소에 교과서 원문을 넣지 않았다. 제공 후 출판사·판본·단원·성취기준·문제 유형·풀이 전략·난이도를 비교한다. 분석 자료는 공개 코드와 분리하고, 공개 문제은행에는 직접 제작한 새로운 문제와 독립 검산·풀이를 넣는다. 교과서 문항·그림·해설 원문을 그대로 공개할 필요가 있다면 이용허락 범위를 먼저 확인한다. 파일 분석은 모델 자체를 영구 재학습시키는 방식이 아니다.

다음 기능은 별도 단계: 단답형/좌표/벡터 입력용 정답 스키마와 동치 판정 → 제한 범위를 명시한 자동 채점 → 교과서 분석 기반 창작 문제 확장 → 기기별 필기 사용성 개선.
